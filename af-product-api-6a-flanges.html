API 6A Flanges Manufacturer and Stockist

Product Overview

High-pressure flange range for oilfield and wellhead applications. India Steel Industries lists this product within its industrial piping and process product range. The product is intended to be selected according to material grade, dimensions, pressure class, connection type and service conditions.

More Details of the Product

This product is suitable for professional piping, fabrication and maintenance environments where dimensional accuracy, dependable connections and service compatibility are important. Final configuration can be specified to match project drawings, applicable standards and operating conditions.

Specifications

  • Materials: Carbon Steel, Stainless Steel, Alloy Steel and other specified grades
  • Standards: ASME / ANSI / API / EN / BS / IS as applicable
  • Face / connection: Product-specific raised face, flat face, threaded, socket weld or weld neck
  • Size and pressure class: As specified for the application
